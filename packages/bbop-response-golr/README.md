# bbop-response-golr

## Overview

Response type and API for handling the responses from a GOlr instance
(a Solr server with a structured schema) in a standard way.

In addition to the base functionality provided by
`bbop-rest-response`, this class adds response checks, paging helpers,
document access helpers, facet access, query filter parsing, and
highlight handling.
